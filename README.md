# NickRadar

**Поиск свободных юзернеймов Telegram и проверка занятости любого @имени.**
Тёмный интерфейс, два инструмента, ноль зависимостей и бесплатный хостинг.

- **Username Checker** — вводишь имя, получаешь вердикт: свободно, занято (и кем), продаётся на Fragment.
- **Поиск** — задаёшь длину, приставку, окончание и основу; сервис перебирает кандидатов и возвращает
  только те имена, которые реально можно занять.

## Как устроено

| Часть | Что делает | Где работает |
| --- | --- | --- |
| Страница (`public/`) | генерация имён, словари, кэш и чёрный список, интерфейс | браузер, отдаётся как статика (GitHub Pages / Vercel) |
| Проверка (`src/`, `api/`, `server.js`) | отвечает «занято ли это имя» по `t.me` и `fragment.com` | serverless-функция (Vercel) или локальный сервер |

Разделение сделано специально: браузер делает всю «тяжёлую» и состоятельную работу, а серверу остаётся
одна stateless-операция — проверить пачку имён. Поэтому всё укладывается в бесплатные тарифы:
Pages отдаёт статику, Vercel Hobby — функции. Никаких баз данных и платных дисков.

## Быстрый запуск

```powershell
cd tg-username-finder
npm start              # http://localhost:3000
```

Если `node` и `npm` не в `PATH` (обычная ситуация на Windows) — запусти **`start.cmd`** двойным кликом:
он сам находит `node.exe`. Зависимостей нет, устанавливать ничего не нужно.

Демо-режим без обращения к сети (вердикты выдуманные):

```powershell
start.cmd --mock       # или npm run start:mock
```

## Инструменты

### Username Checker

Разовая проверка имени через `POST /api/check`: `free`, `taken`, `collectible`, `unverified`.
Для занятого имени показывает, кто это (пользователь, бот, канал), для коллекционного — статус продажи,
цену и владельца.

### Поиск свободных имён

Настройки живут в сворачиваемой панели:

| Настройка | Что делает |
| --- | --- |
| Длина | 5–14 символов; короче 5 Telegram бесплатно не выдаёт |
| Приставка | что должно быть в начале: `iam`, `real`, `the` (есть кнопки-пресеты) |
| Окончание | что должно быть в конце: `1337`, `777`, `bot` |
| Случайные цифры в окончании | вместо фиксированного окончания подставляются случайные цифры |
| Основа | «словарное слово» (en/ru), «произносимое» (`bravilo`) или «случайные буквы» |
| Добивать произносимыми | когда слова в словаре закончились |

Имя собирается как `приставка + основа + окончание`, и сервис следит, чтобы результат был валидным
юзернеймом Telegram: 5–32 символа, латиница/цифры/`_`, начинается с буквы. Под настройками есть живая
подсказка формата: `iam + произносимое (4) + 1337 = 11 симв.`

Результаты разложены на три блока:

- **«Свободны и не продаются»** — подтверждено и t.me, и Fragment;
- **«Продаются на Fragment»** — коллекционные имена со статусом, ценой и владельцем;
- **«не подтверждено»** — Fragment не ответил, в свободные такие не попадают.

Кнопка **«Не дали занять»** на карточке добавляет имя в чёрный список в браузере: оно больше не предлагается.
Чёрный список и кэш проверок хранятся в `localStorage`, на сервер не уходят.

## Как проверяется занятость

Официального публичного API «свободен ли юзернейм» у Telegram нет, поэтому проверка двухступенчатая.

**1. Публичная страница `https://t.me/<имя>`** (токен не нужен):

| Что на странице | Вывод |
| --- | --- |
| блок `class="tgme_page_title"` — реальное имя или название | имя **занято** |
| вместо него заглушка `class="tgme_page_icon"` | имя выглядит свободным, идём дальше |
| страница не открылась, 429 | результат **не подтверждён** |

**2. `https://fragment.com/username/<имя>`** — площадка Telegram для коллекционных имён:

| Что на странице | Вывод |
| --- | --- |
| детальная страница со статусом `Sold` / `On sale` / `On auction` / `Available` | имя **коллекционное**: бесплатно не отдадут |
| страница поиска, строка `<имя> … Unavailable / Not for sale` | имя **не коллекционное** → подтверждённо свободно |
| fragment.com недоступен | результат **не подтверждён** |

**3. Bot API `getChat`** — резерв, когда t.me недоступен: `200 OK` — занято, `401` — токен неверен, `429` — пауза.

> ⚠️ Только через `getChat` проверять нельзя: **Bot API не видит обычных пользователей** и на занятое имя
> отвечает `400 chat not found`. На замерах это давало 5 ложных «свободен» из 24 (`@acrylate`, `@krispies`,
> `@repacify` оказались заняты), поэтому вердикт `getChat` «не найден» не считается доказательством свободы.

## «Призрачные» имена

Отдельная категория: имя никем не занято и не продаётся, но Telegram отказывается его выдать — «эта ссылка
уже занята». Обычно владелец аккаунта или канала удалён либо заблокирован, а имя осталось зарезервированным.
Проверено на `@sycees`, `@wincer`, `@cleach`: их страницы на t.me и fragment.com **побайтово совпадают**
со страницами свободных имён, поэтому скрейпингом такие имена не отличаются.

Для этого и нужна кнопка «Не дали занять»: отметки копятся в браузере и отсеивают подобные имена.
Дополнительно в `public/data/blocked.json` лежит общий стартовый чёрный список — имена, которые
Telegram не отдал другим пользователям.

## Выложить в интернет (бесплатно)

Пошаговая инструкция без командной строки — в **[DEPLOY.md](DEPLOY.md)**. Коротко:

- **Netlify** (Starter, бесплатно, **не просит телефон**) — рекомендованный путь: импортируешь репозиторий,
  настройки берутся из `netlify.toml`, функции лежат в `netlify/functions/`. Работает всё сразу.
- **Vercel** (Hobby, бесплатно) — тоже поддерживается «из коробки» (`vercel.json` + `api/`), но при регистрации
  Vercel требует подтвердить аккаунт по номеру телефона, и на российские номера SMS часто не доходит.
- **GitHub Pages** — по желанию, для «красивого» адреса: workflow `.github/workflows/deploy-pages.yml`
  публикует папку `public/`, а адрес API указывается в `public/config.js`.

## Словари

Собираются в два шага (в репозитории лежит только готовый результат для браузера):

```powershell
npm run build:dict      # скачивает english-words и русские существительные в data/
npm run build:webdict   # нарезает их по длинам в public/data/<язык>/<длина>.txt + manifest.json
```

Нарезка нужна, чтобы страница тянула только нужную длину: например, для поиска 8-буквенных слов
загружается один файл на ~450 КБ вместо трёх с половиной мегабайт всех слов.

## Тесты

```powershell
npm test               # офлайн: генератор имён, кэш/чёрный список, цикл поиска
npm run test:netlify   # Netlify-функции (с живой проверкой двух имён)
npm run test:smoke     # живой API: нужен запущенный сервер (и сеть для реальных проверок)
```

## API

- `GET /api/config` — режим и лимиты (фронтенд работает и без него);
- `POST /api/check` — `{name, token?}` — проверка одного имени;
- `POST /api/batch` — `{names: [...], token?}` → `{results, partial}` — проверка пачки (до 20 имён).

## Честные ограничения

- **От 5 символов.** Имена короче — только платные аукционы на [Fragment](https://fragment.com).
- **Короткие и словарные имена почти все заняты.** Для 5–7 символов шанс близок к нулю; реальные находки —
  с 8+ символов или в режиме произносимых сочетаний.
- **Проверка идёт батчами.** Одна serverless-функция проверяет до 20 имён и живёт считанные секунды,
  поэтому поиск автоматически идёт порциями по 12 имён (~2–3 имени в секунду). На бесплатном тарифе это
  норма, но за один проход реально проверить 100–200 имён.
- **Коллекционные имена — только за деньги**, «призрачные» — не отдаются вовсе.
- **Проверка не официальная.** t.me и fragment.com — публичные страницы, их разметка может измениться.
  Перед занятием имени открой его в приложении Telegram.
- **Токен — это доступ к боту.** Не публикуй `.env` (он в `.gitignore`).
